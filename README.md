# ANOTHER LIFE v0.6

Android / GitHub Pages 用プロトタイプ。入力した略歴を自動上映し、過去の小さな選択から別の物語を体験します。

## 更新
GitHub リポジトリのルートにある `index.html`, `app.js`, `style.css`, `sw.js` を同名で置き換え、コミットしてください。デプロイ完了後にシークレットタブで確認。

## 今回の内容
- 呼び名・年齢・最大5つの出来事・最大2人の登場人物を登録
- 年齢順にMY LIFEを上映（字幕間隔 4.2秒、v0.5から+2秒）
- 恋愛・仕事・家族・友人・自分の5カテゴリから選択
- 選択によって異なる直後と後日の物語を表示
- すべての入力は端末のlocalStorageに保存、サーバー送信なし

## 制限
- 分岐はカテゴリごとの短いシナリオであり、入力した人生から自由な長編映像を生成するものではありません。
- v0.5の保存データは引き継ぎません。
- ブラウザのサイトデータを削除すると入力も消えます。
