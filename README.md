# ANOTHER LIFE PWA v0.1

スマホのブラウザで動く、小さな人生分岐ゲーム。HTML/CSS/JavaScriptのみで構成され、外部ライブラリやアカウントは不要です。

## 一番手軽な試し方

1. ZIPを解凍して `index.html` をブラウザで開くと、基本的なゲームは動きます（スマホのファイル表示方法によっては制限があります）。
2. **ホーム画面へのインストール・オフライン利用にはHTTPS配信が必要**です。GitHub PagesやNetlify Drop等の静的サイトホスティングにフォルダ内のファイルを配置し、HTTPSの公開URLをChromeで開きます。
3. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選択します。ブラウザの条件によって表示名は変わります。

### Netlify Drop の例（スマホのみ）

Netlifyにログインし、https://app.netlify.com/drop でサイトフォルダをアップロードします。スマホのブラウザではフォルダのアップロードが難しい場合があります。その場合はZIPを展開したファイルをGitHubリポジトリにアップロードしてGitHub Pagesを有効にする方法、またはPCからアップロードする方法を使ってください。**このZIPをダウンロードしただけではインターネット上に公開されません。**

## 編集

- `app.js` の `chapters`：物語と選択肢
- `app.js` の `futures`：未来の選択
- `app.js` の `actions`：小さな一歩
- `style.css`：配色・文字・ボタン
- `app.js` の `drawScene()`：キャラクターと街のアニメーション

編集後、ホスティング先に再アップロードすると反映されます。変更が見えない場合はChromeで再読み込みしてください。

## 注意点

- 本版はシナリオ分岐の**簡易版**です。選択の結果は次章の回想に反映されますが、長期的な物語分岐やAI動画生成は未実装です。
- 画面上のキャラクターはCanvasで描くオリジナルの簡易アニメーションです。
- 入力内容は端末のlocalStorageにのみ保存され、サーバーには送信されません。ブラウザデータ削除で消えます。
- 公開サイトのURLを知る人はアクセスできます。個人情報は入力しないでください。
- PWAはAPKではありません。
